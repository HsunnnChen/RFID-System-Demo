# RFID 藥品批次交接互動示範（v2）

RFID 批次辨識與藥品流程追蹤系統的互動示範頁面（概念模擬），用於全國醫學工程創意競賽決賽報告。
v2 把示範從「藥局出庫」延伸到「病房簽收」。

## 內容

五個步驟，加上一個後台紀錄頁：

1. **依醫囑建立藥籃**：選擇病房醫囑，系統帶入藥品並分流。一般藥品放進綁定醫囑的智慧藥籃，高風險管制藥與冷藏藥品貼一次性標籤
2. **掃描比較**：逐項掃描與整籃感應的時間比較
3. **感應箱內部**：腔體感應的四個運作階段
4. **防呆核對、封籤與出庫**：管制藥雙人核對；冷藏藥品離開冰箱後 15 分鐘內要放入保冷隔層；藥籃的「保冷隔層記錄器」（每籃 1 個、可重複使用）記錄隔層溫度，可模擬隔層升溫觸發示警。全部完成後貼上防拆封籤才能出庫
5. **送達病房與簽收**：病房端再讀一次，核對送達病房、封籤、管制藥 UID，並讀取隔層記錄器的轉運途中溫度；可模擬封籤被撕開、送錯病房、管制藥被調換、途中隔層未蓋好。全部通過才能簽收，否則拒收
6. **後台紀錄**：每一批的品項、簽核、封籤、溫度與交接過程（出庫 → 病房讀取 → 簽收／拒收），含三筆示範資料

支援淺色／深色模式、講者模式與全螢幕。

後台紀錄頁有「清除紀錄」，可選擇：
- **只清除練習紀錄**：刪除你們操作產生的批次與系統紀錄（含進行中的批次），保留 3 筆示範資料
- **全部清空（含示範）**：後台變成空白

上方「重新開始」會清除練習紀錄、恢復示範資料並回到步驟 1。紀錄只存在瀏覽器分頁的記憶體中，重新整理頁面會清空練習紀錄，示範資料會回來。

## 使用方式

單一 HTML 檔，不需要安裝或建置。

- **本機**：直接用瀏覽器開啟 `index.html`
- 網址後加 `#step5` 直接開啟病房簽收，`#step6` 直接開啟後台紀錄

字體由 Google Fonts 載入，離線時會自動改用系統字體。

## 資料說明

- 本頁所有數值、辨識畫面與計時皆為模擬，不代表實體原型或實測結果
- 後台紀錄中標示「示範」的三筆批次為預先放入的示範資料
- 逐項掃描的單支秒數（5.4–6.8 秒）為本團隊模擬假設值，未引用特定文獻
- 「整籃感應 1 秒內」為本團隊系統設計目標值，尚待原型實測驗證
- 一般藥品的品項與數量正確性由調劑端既有條碼核對與醫囑負責；感應箱讀取藥籃標籤，封籤用來確認出庫後未被開啟
- 冷藏藥品的單品標籤只負責身分（UID、批號、效期），不測溫：離開冰箱到放入保冷隔層之間以 15 分鐘時限管控；放入後由每籃一個、可重複使用的隔層記錄器記錄隔層溫度、異常即時示警，非逐支貼溫度標籤
- 封籤假設使用防拆 RFID 標籤；病房端讀取與轉運流程為系統規劃示意
